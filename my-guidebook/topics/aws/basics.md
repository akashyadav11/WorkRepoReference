# AWS Basics

## Key Concepts
- **Region**: Physical location of data centers.
- **Availability Zone**: Isolated data center within a region.
- **VPC**: Virtual Private Cloud for networking.

## Core Services
- **EC2**: Virtual machines.
- **S3**: Object storage.
- **Lambda**: Serverless functions.

# Data Pipelines

## Pipeline Stages
- **Ingestion**: Collecting data from sources.
- **Transformation**: Cleaning and processing.
- **Storage**: Storing processed data.
- **Serving**: Making data available for use.

## Tools & Services
- **Ingestion**: Kafka, Kinesis.
- **Transformation**: Spark, Glue, dbt.
- **Storage**: S3, HDFS, Redshift.

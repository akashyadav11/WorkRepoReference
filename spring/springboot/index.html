    Lifecycle of a Spring Bean

    1. Application Start

      • Spring application starts, initializing the runtime environment.

    2. IOC Container Initialization

      • Spring IoC container starts.
      • Configuration metadata is loaded (XML, annotations, or Java config).

    3. Bean Instantiation

      • Container creates an instance of the bean using its constructor.

    4. Dependency Injection

      • Dependencies are injected into the bean.
      • @Autowired is used to inject other beans by type.

    5. @PostConstruct Method Execution

      • Runs after dependencies are injected and before the bean is used.
      • Used for initialization tasks.

    6. Bean Usage

      • Bean is ready to be used by the application.

    7. @PreDestroy Method Execution

      • Runs before the bean is destroyed.
      • Used to clean up resources like closing DB connections.

    8. Bean Destruction

      • Container removes the bean from memory.

    Using Dependency injection,we can make our class indepdent of it dependencies It helps to remove the dependency on concrete implementation and inject the dependencies from external source.

    Types of Injection: 1. field injection: 1. dependency is set into fields of class directly. 2. Very simple and easy to use 3.     1. Constructor Injection
    2. Dependency get resolved at the time of initialization of the object itself. public class user{ Order order; @Autowired public User(Order order){ this.order=order; System.out.println(""); } }
    3. When more than 1 constructor is present,then using @Autowired on constructor is mandatory

    why constructor injection is recommended(Advantages)

    All mandatory dependencies are created at initliazation itself.to avoid NPE runtime and unnecessary null can be avoided to. we can create immutable object using constructor injection Fail fast :if there is any missing dependency , it will fail during compilation itself,rather than failing run time.

    -Circular dependency : 1. we should refractor the code and remove the cycle dependency ,remove code to separate class 2. using @lazy on autowired annotation:Spring will create proxy bean instead of instance of bean 3. using @PostConstruct - Unsatisfied dependency : 1. @Primary is an annotation that marks a bean as the default choice when multiple candidates are available for autowiring. It helps Spring avoid confusion when it encounters more than one bean of the same type 2. @Qualifier :When you have multiple beans of the same type, Spring gets confused during autowiring. @Qualifier helps resolve this ambiguity by specifying which bean to inject. @Component("fooFormatter")

    • Springboot provides JdbcTemplate class, which helps to remove all the boiler code. Driver class loading - JdbcTemplate load it at the time of application startup in DriverManager class. DB Connection Making - jdbcTemplate takes care of it, whenever we execute any query. Exception Handlingin Plain JDBC, we get very abstracted 'SQLException' but in jdbcTemplate, we get granular error like DuplicateKeyException, QueryTimeoutException etc.. (defined in org.springframework.dao package). Closing of the DB connection and other resources - when we invoke update or query method, after success or failure of the operation, jdbcTemplate takes care of either closing or return the connection to Pool itself.     JPA Architecture

    1. peristance unit :Logical grouping of Entity classes which share same configurations.db connect and driver etcs and it used to create EntityManagerFactory
    2. EntityManagerFactory:
    3. Using Persistence Unit configuration, EntityManagerFactory object get created during application startup.
    4. If any property is not provided, default one is picked and set.
    5. 1 EntityManagerFactory for 1 Persistence Unit.
    6. This class act as a Factory to create an object of EntityManager.
    7. Entity Manager and Peristance Context Its an interface in JPA that provides methods to perform CRUD operations on entities. persist() (for saving) merge() (for updating) find() (for fetching) remove() (for deleting) createQuery() (for executing JPQL queries)
    8. EntityManager interface methods are implemented by JPA Vendors like Hibernate etc.
    9. EntityManagerFactory helps to create an Object of EntityManager. PersistenceContext: Consider its a first level cache.
    10. For each EntityManager, PersistenceContext object is created, which hold list of Entities its working on. Also manage the life cycle of entity.

    How to start

    Here are the steps to build a simple Spring boot application.

    Generate a quick Java project with Maven command.

    Update pom.xml with the Spring web and other Spring boot dependencies.

    Add SpringApplication.run() method to bootstrap Spring application.

    Do a Maven clean build using mvn clean package command.

    Execute command mvn spring-boot:run to run the application.
